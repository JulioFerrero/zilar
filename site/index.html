Safety is code, not prompts.

An AI that can spend money or act for you needs limits it cannot talk its way around. Every rule below is enforced by the platform.

  • It can never overspend. Each AI has its own key with a hard cap, checked before the call.
  • Risky actions need a human. They show up as cards in the chat: Approve, Deny, or Always allow here.
  • One tap stops it. The kill switch halts an AI, and nothing it was doing lands afterwards.
  • History cannot be rewritten. The audit log is append-only. The database itself refuses edits and deletes.
  • AI-written code stays in a box. It runs in a sandbox with no files, no environment and a strict network allowlist.
  • Secrets stay secret. Provider keys are sealed with AES-256-GCM and never reach logs or tool code.

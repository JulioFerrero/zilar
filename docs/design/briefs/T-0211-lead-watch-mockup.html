How it behaves

  • Refreshes every 3 s in a background process; the animation never freezes.
  • Fits the window: under 50 columns the tracker loses its bars, the sparkline and file names drop.
  • ctx turns yellow at 150k and red at 200k: that is when a session gets expensive.
  • The watch window switches to FiraCode Nerd Font Mono so the icons render.
  • q quits and leaves the terminal clean.

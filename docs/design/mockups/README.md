# Approved mockups (D24, 2026-09-28)

The source of Julio's approved redesign canvas. The files are in the canvas's "Design Component" format: plain HTML and inline styles, plus a small template layer.
- `{{accent}}` is `#ededed` (text on it is `#0a0a0a`, with text-shadow `0 1px 0 rgba(255,255,255,0.7)`).
- `{{bgClass}}` is `dots`.
- The CSS classes (`btn-primary`, `btn-icon`, `well`, `seg-on`, `bubble-out`, `bubble-in`, `bubble-gen`, `raised-pill`) are defined in each file's `<style>`.

Read them for exact values. Don't import them into the app. `docs/design/ui-style.md` is the written spec.

- `Main.dc.html`: desktop, 1440×900, a chat with an AI mid-reply.
- `Mobile.dc.html`: the mobile chat list, 390×844.

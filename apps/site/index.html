Runs on your server.

One small Linux server runs everything: the chat, the web app, its database and the HTTPS certificate. Your messages and their history never leave it.

You need

  • A Linux server with Docker and its Compose plugin.
  • A domain whose A record points at that server, with ports 80 and 443 open.
  • An SMTP account. Zilar has no passwords, so sign-in codes arrive by email.

Zilar is early and not production-ready yet. The code is private for now and shared with everyone who requests access.

  1. git clone <your access link> zilar && cd zilar

    Get the code with the link you receive after requesting access.

  2. ./deploy/zilar init

    Asks for your domain and email, generates every password and key, and saves them to deploy/.env. Add your SMTP details there. Answer localhost to try it on your laptop first.

  3. ./deploy/zilar up

    Starts the five containers: Postgres, the ejabberd chat server, the Zilar server, the web app and Caddy, which fetches the HTTPS certificate. It waits until all of them are healthy.

  4. ./deploy/zilar create-admin

    Prints a one-time invite code. Open your domain, sign up with your email and paste the code. You are the first member.

Something off? ./deploy/zilar doctor checks DNS, ports, keys and disk and says how to fix each problem.
